# 🧠 Brain Tumor Detection System

An AI-powered Brain Tumor Detection System developed using **Deep Learning (CNN)** and **TensorFlow/Keras**. This project classifies brain MRI images as **Tumor** or **No Tumor** through an interactive **Streamlit** web application.

---

## 📖 Overview

This project demonstrates the complete workflow of an AI application—from data preprocessing and model training to deployment. Users can upload a brain MRI image through the Streamlit dashboard and receive a prediction with a confidence score.

---

## ✨ Features

- 🧠 Brain MRI image classification
- 🤖 CNN model built with TensorFlow/Keras
- 📤 Upload MRI images for prediction
- 📊 Prediction with confidence score
- 🌙 Clean and interactive Streamlit interface
- 🚀 Easy to run locally

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/bashir030497-cloud/brain-tumer-detecction-sytem.git
```

### 2. Open the project folder

```bash
cd brain-tumer-detecction-sytem
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

### 4. Download the model files

Since the trained model files are too large for GitHub, download them from the links below.

**Model File 1**

https://drive.google.com/file/d/1EHts3e6_WtMdh_EI07snEc_35aFb8u2j/view?usp=sharing

**Model File 2**

https://drive.google.com/file/d/1cikmuIAFfSAYJvGb97gYdzGc85K95HK6/view?usp=sharing

Place both downloaded files inside the project folder.

### 5. Run the application

```bash
streamlit run app.py
```
