# 🧠 NeuroScan AI - Brain Tumor Detection

This is a Deep Learning project that detects brain tumors from MRI images using a Convolutional Neural Network (CNN).

## Features

- Brain MRI image classification
- CNN model built with TensorFlow/Keras
- Streamlit web application
- Prediction confidence score
- Clean and interactive dashboard

## Technologies Used

- Python
- TensorFlow/Keras
- Streamlit
- NumPy
- Pandas
- Matplotlib
- OpenCV

## Dataset

Brain MRI images for brain tumor classification.

## Installation

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
streamlit run app.py
```
